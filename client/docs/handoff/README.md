# Handoff log

Mỗi lần thay đổi = **một file md** trong thư mục này.

Quy ước tên file: `YYYY-MM-DD-NN-slug-ngan.md` (`NN` = thứ tự trong ngày).

Nội dung mỗi file:

- **Yêu cầu** — user yêu cầu gì
- **Thay đổi FE** — file nào, làm gì
- **Ảnh hưởng API** — có đổi hợp đồng API không (nếu có → cập nhật `docs/API.md`)
- **Ghi chú / việc còn lại**

Quy tắc: chỉ sửa FE (`src/frontend`, `src/routes` phần UI, `src/styles.css`).
Không sửa `src/backend`.
