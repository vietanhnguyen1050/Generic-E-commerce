# 2026-08-10-02 — Đổi ngôn ngữ (i18n) & chế độ tối

## Mục tiêu
Thêm nút đổi ngôn ngữ (VI/EN) với context riêng, và nút bật/tắt chế độ tối.

## Thay đổi (chỉ FE)
### File mới
- `src/frontend/lib/i18n.tsx` — `I18nProvider`, hook `useI18n()` (`lang`, `setLang`, `toggleLang`, `t(key, vars)`).
  - Từ điển `vi` / `en` khai báo trong file, key dạng dot-namespace (`header.*`, `topbar.*`, `common.*`, `theme.*`).
  - Hỗ trợ nội suy biến: `t("topbar.freeShipping", { amount })`.
  - Lưu lựa chọn vào `localStorage["zenova.lang"]`, đọc trong `useEffect` để tránh lệch SSR; cập nhật `document.documentElement.lang`.
- `src/frontend/lib/theme.tsx` — `ThemeProvider`, hook `useTheme()` (`theme`, `setTheme`, `toggleTheme`).
  - Toggle class `dark` trên `<html>` + `color-scheme`.
  - Lưu `localStorage["zenova.theme"]`, mặc định theo `prefers-color-scheme`.
- `src/frontend/components/site/LanguageToggle.tsx` — dropdown chọn ngôn ngữ (cờ + tên).
- `src/frontend/components/site/ThemeToggle.tsx` — nút icon Sun/Moon.

### File sửa
- `src/routes/__root.tsx` — bọc app bằng `ThemeProvider` > `I18nProvider` (ngoài `AuthProvider`/`CartProvider`).
- `src/frontend/components/site/Header.tsx` — thêm 2 nút vào cụm action bên phải; chuyển các chuỗi tĩnh sang `t(...)`; input tìm kiếm dùng `bg-background` thay `bg-white` để đúng dark mode.
- `src/styles.css` — bổ sung token dark cho `--surface`, `--ink`, `--ink-foreground`, `--brand*`, `--teal*`, `--gold*`, `--gradient-ink`, `--shadow-card/lift`.
- Tương phản dark mode: `text-ink` đứng một mình → `text-foreground` (ProductCard, CartPage, CheckoutPage, OrderSuccessPage); `bg-accent text-ink` → `text-accent-foreground` (HomePage, CategoryTile).

## Không đổi
- `src/backend/*`, `src/routes/api/*`, `src/shared/*` giữ nguyên. Không thay đổi hợp đồng API → `docs/API.md` không cần cập nhật.

## Cách mở rộng
Thêm chuỗi mới: khai báo key ở cả `vi` và `en` trong `dictionaries` của `src/frontend/lib/i18n.tsx`, rồi dùng `const { t } = useI18n()`.

- Playwright: bấm nút chế độ tối → `<html class="dark">`; chọn English → header hiển thị "Free shipping on orders from 500.000đ", "All products", "Account".
